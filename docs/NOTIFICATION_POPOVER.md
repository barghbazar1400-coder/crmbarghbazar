# پنل سریع اعلان‌ها در CRM برق بازار

## رفتار جدید زنگوله
- در همه صفحات CRM، کلیک روی زنگوله **بدون ترک همان صفحه** یک پنل بازشو زیر آیکن را نمایش می‌دهد.
- پنل آخرین ۸ اعلان (از نتیجه موجودِ polling هر ۱۰ ثانیه) را با دسته، عنوان، خلاصه، زمان و وضعیت مطالعه نمایش می‌دهد.
- عنوان هر اعلان لینک مستقیم به بخش مربوطه است (مثلاً پیام، کار، یا جزئیات وظیفه). مقصدهای خارج از مسیر مجاز CRM سمت کلاینت رد می‌شوند.
- دکمه «خواندم» برای اعلان‌های معمولی در همان پنل از مسیر AJAX و با nonce ثبت می‌شود و شمارنده زنگوله را به‌روزرسانی می‌کند.
- «راهنمایی مدیر» در این پنل **دکمه خواندم ندارد**؛ کارمند باید از داخل خود تسک و پس از مطالعه راهنمایی، آن را به‌صورت مستقل تأیید کند.
- کلیک بیرون پنل، کلید Escape و دکمه بستن پنل را می‌بندند؛ کلید Escape فوکوس را به زنگوله بازمی‌گرداند.
- لینک «همه اعلان‌ها و تنظیمات» تاریخچه کامل، ارسال اطلاعیه و تنظیمات صدای پیام/پوش ویندوز را در صفحه اصلی حفظ می‌کند.
- بدون JavaScript، لینک اصلی زنگوله همچنان به صفحه اعلان‌ها می‌رود.

## امنیت و سازگاری
- داده‌ها فقط از `crmb_notice_list` برای کاربر فعلی و endpoint دارای `check_ajax_referer` خوانده می‌شوند. هیچ منبع اشتراکی و هیچ تغییر دیتابیس ایجاد نشده است.
- عنوان، خلاصه و تاریخ با `textContent` درج می‌شوند، نه HTML. لینک‌ها با `safeDestination` اعتبارسنجی می‌شوند.
- اعلان‌های قدیمی یا پیام خصوصی روی دسکتاپ بازپخش نمی‌شوند؛ منطق فعلی notification sound و Windows Push تغییر نکرده است.
- محل پنل در موبایل به عرض صفحه سازگار است.

## آزمون
```bash
php -l page-main.php
php -l inc/notifications.php
node --check assets/js/crmb-notices.js
node tests/notifications-popover.js
node tests/notifications-client.js
node tests/notifications-sound.js
php tests/notifications.php
```

پس از استقرار باید با کاربر دارای اعلان جدید و اعلان خوانده‌شده بررسی شود: زنگوله پنل را باز کند، لینک هر اعلان مقصد صحیح داشته باشد، بستن و Escape کار کند، شمارنده به‌روز شود و در دسکتاپ و موبایل محتوا از صفحه بیرون نزند.
